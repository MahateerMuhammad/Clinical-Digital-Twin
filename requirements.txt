# torch is NOT required to serve this project and is deliberately excluded.
#
# `src/llm/twin_projection.py` reimplements the Phase 7 encoder forward pass in
# NumPy for exactly this reason: on macOS x86_64 the last published wheel
# (torch 2.2.2, built against NumPy 1.x) segfaults when a LightGBM booster is
# unpickled into the same process. `tests/conftest.py` stubs it out so the whole
# suite can run in a single process.
#
# Install it only to (a) re-export encoder weights via
# scripts/maintenance/export_encoder_weights.py, or (b) run the local LLM
# backend in src/llm/backends.py. Both are offline, one-off jobs:
#
#   torch==2.2.2
#   transformers>=4.44.0
